SISTEMA INTELIGENTE DE MONITOREO Y CONTROL DE TEMPERATURA Y HUMEDAD AMBIENTAL

Sensor: DHT22 Digital (Pin D2)

Actuador 1: Ventilador mediante Relé (Pin D7)

Actuador 2: Lámpara mediante Relé (Pin D8)

Pantalla: LCD 16x2 I2C (Pines A4 / A5)

Simulación: Proteus 8.17 + COMPIM

Backend: C# ASP.NET Core (.NET 10) + SignalR

Base de Datos: SQL Server
